# Website-standards-around-the-globe
Dieses Repository analysiert und vergleicht Websites aus verschiedenen Ländern, um Unterschiede in Größe, Layout und technischen Standards sichtbar zu machen.

## Inhalt

- **charts/** – Enthält Grafiken und Visualisierungen der analysierten Websites.
- **csv/** – Rohdaten und aggregierte CSV-Dateien mit Website-Metriken.
- **domain_lists/** – Listen von Domains pro Land, die für die Analyse verwendet werden.
- **scripts/** – Python-Skripte zum Sammeln, Verarbeiten und Visualisieren der Daten.
